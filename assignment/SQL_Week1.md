# 3️⃣ 확인 문제

## 🧩 문제 1

포켓몬 게임이나 이커머스 산업과 같이 다양한 산업에서는 각기 다른 데이터가 존재합니다. 다음 중 하나의 산업을 선택하고, 해당 산업에서 수집하고 활용될 수 있는 데이터 항목, 즉 컬럼 5가지를 자유롭게 상상하여 나열해주세요.

예시 산업:
- 온라인 음식 배달
- 스마트 헬스 케어
- 중고 거래 앱
- 교육 플랫폼

풀이 과정:

```
- 선택한 산업: 온라인 음식 배달
- 떠올린 컬럼 5가지: 주문 음식, 주문 수량, 가격, 주문자 정보, 해당 라이더
- 해당 컬럼이 필요하다고 생각한 이유: 온라인으로 음식 배달을 할 경우, 주문자 정보부터 어떤 음식을 얼마나 주문해서 매출이 얼마나 됐고 라이더 비용이 얼마나 들었는지 등의 정보를 주/월/년 단위로 요약해볼 수 있다.
```

## 🧩 문제 2

이번 강의를 통해 SQL이 왜 필요하다고 느끼는지, SQL을 통해 본인이 어떤 것을 해내고 싶은지를 자유롭게 작성해주세요.

풀이 과정:

```
- SQL이 필요하다고 느낀 이유: 요즘 많은 기업에서 데이터 베이스를 다루기 위해 sql을 사용한다고 해서 이번 기회에 열심히 배워보고 싶습니다.
- SQL로 해보고 싶은 일: 데이터에 조건을 걸어, 추출, 변환, 요약 등을 해보고 싶습니다.
- 앞으로 SQL을 공부할 때 기대되는 점: 실제 프로그램을 사용하여 데이터를 다루어보는 것이 기대가 됩니다.
```
